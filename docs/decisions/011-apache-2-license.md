# ADR 011: Apache-2.0 license

**Status:** Accepted

**Context**

The framework is intended for enterprise adoption. Organizations may want permissive commercial use and explicit patent protection. The license should reflect that intent.

**Decision**

Use Apache-2.0.

**Reasons**

- Permissive use for commercial and internal purposes
- Explicit patent grant language
- Familiar to enterprises
- Suitable for a framework that may eventually be used across many organizations

**Alternatives considered**

- MIT
- GPL-family licenses
- Dual-licensing models

**Consequences**

- Apache-2.0 is a good fit for enterprise adoption and patent protection concerns.
- License choice may still need to be revisited if redistribution, copyleft, or commercial packaging requirements change.
- License headers and attribution should be applied consistently across the repository.
